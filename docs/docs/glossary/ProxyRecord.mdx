A Proxy Record is a record that is able to send HTTP requests to another service on behalf of an experience.

Proxies store the secret information (like API keys) that the destination service requires and apply it to the
request right before it is sent. This makes it possible to use a service that is secured by an API key without
having to include the API key in the experience itself.
